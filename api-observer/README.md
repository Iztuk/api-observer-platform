# API Observer

## Overview

API Observer is a self-hosted API observability platform that monitors and evaluates HTTP traffic against OpenAPI contracts and custom security rules. It produces structured findings that help developers identify unexpected behavior, contract violations, and potential security concerns.

## Features

- SDK-based HTTP event ingestion
- Request, response, and failure event processing
- OpenAPI request and response auditing
- Host-specific custom rules
- JSONL job and findings storage
- Concurrent worker processing
- YAML and JSON contract support

## Quick Start

```
git clone https://github.com/Iztuk/api-observer.git
cd api-observer
go run ./cmd/api-observer
```

## Configuration

API Observer is configured through environment variables.

All configuration values are optional. When a variable is not set, API Observer uses its default value.

| Variable                    | Default                 | Description                                                                |
| --------------------------- | ----------------------- | -------------------------------------------------------------------------- |
| `API_OBSERVER_ADDR`         | `:24899`                 | Address and port used by the API Observer HTTP server.                     |
| `API_OBSERVER_JOB_LOG`      | `./logs/jobs.jsonl`     | Path used to store processed request, response, and failure jobs.          |
| `API_OBSERVER_FINDINGS_LOG` | `./logs/findings.jsonl` | Path used to store findings generated by OpenAPI and custom rule auditing. |
| `API_OBSERVER_QUEUE_SIZE`   | `1000`                  | Maximum number of jobs that can wait in the processing queue.              |
| `API_OBSERVER_WORKER_COUNT` | `5`                     | Number of workers that process queued jobs concurrently.                   |

Relative file paths are resolved from the directory where API Observer is started.
